# Agent Note: 桌面端界面改版：按领域拆侧栏，Fluent 原生加长春花蓝

Status: proposed

## Problem

主人 2026-11-25 凌晨说，winhand 桌面端「太丑了」，而且布局不合理：设置里中转、密钥、程序授权全混在一起，应该有序放到侧边栏；会话页从来没用过。

0.14.0 的实情（主人电脑上的截图 `~/.winhand/scratch/ui-review/before-*.png`）：
- **设置页七块堆在一页**：中转、密钥、程序授权、启动、更新、本机数据、关于，滚四屏才到底。「添加密钥」「加入一直允许」都在列表的最底下。
- **窄窗口塌陷**：主人日常窗口约 853×1018 逻辑像素。活动和 MCP 服务两页的左右分栏阈值高于内容区宽度，塌成上下两截：MCP 的服务列表被切掉一半，活动页下面 60% 空着，却写着「在左边选择」。
- **会话页**：长期是空的，却占着一个顶级导航项。
- **视觉**：
  - 黑色系统标题栏配纯白画布，强调色跟着系统走成了炭灰色；
  - 密钥每行四个带框按钮，十五行就是六十个按钮，删除和复制长得一样；
  - 看板娘被裁掉底座，旁边飘着一个状态小绿点。

Gemini 按 impeccable 的 critique 给现状打了 22/40。失败条件：主人在日常窗口里找不到、看不清，或者误点删除。

## Proposal

方案由 Claude 和 Gemini（agy-neon）在 parley t36 讨论两轮定下，视觉和布局以 Gemini 为准。细节在 `desktop/DESIGN.md`（视觉规范）和 `codestable/epics/005-o-桌面端界面改版/PAGES.md`（逐页规范、零依赖样式、截图验收要点）。

- **信息架构**：
  - 侧栏主区：概览、活动、会话、MCP 服务。会话只在有会话时出现，带计数，有会话等人处理时计数变成琥珀色。
  - 「安全与连接」一组：密钥、程序授权、中转，各自成页。
  - 页脚：设置，只留启动、更新、本机数据、关于；有新版本时亮一个点。
  - 侧栏可以折叠到 48 像素（Ctrl+B），折叠后看板娘隐藏，只留状态圆点。
- **视觉**：85% Windows 11 原生 Fluent，15% 品牌签名。
  - 强调色是从图标底色取的长春花蓝：浅色 #4F63D2（配白字 5.19:1），深色 #8EA0F8；
  - Mica 背景，标题栏和内容融为一体；
  - 卡片只用 1 像素描边，不加阴影；
  - 看板娘缩到 88×88、不裁切，旁边是全应用唯一的连接状态锚点。
- **关键交互**：
  - 密钥每行只留「显示」「复制」两个轻按钮，修改和删除进「⋯」菜单；
  - 程序授权的撤销立即生效，右下角提示条给 8 秒「恢复」；
  - 活动页在窄窗口里选中一条后，底部弹出详情抽屉；
  - MCP 服务的分栏阈值降到 568，853 宽时直接左右分栏；
  - 操作反馈改成右下角浮动的提示条，取代右上角的「✓」按钮。
- **不变量**：
  - 密钥显示 30 秒、显示期间窗口不进截图、离开密钥页立即隐藏；
  - 复制不进剪贴板历史；令牌不回显；
  - 后端协议不改。
- **验收**：先做预览底座（假后端加 `WINHAND_DESKTOP_PAGE`），每张票做完在主人电脑上逐页截图，Gemini 对照样稿看视觉，Claude 看功能和代码。
- **执行**：GPT（Codex）按票执行，Claude 审查。

## Alternatives considered

- **引入 CommunityToolkit 的 SettingsCard。** Gemini 第一轮推荐。
  - 最强的理由：现成的 Windows 11 设置行，悬停、焦点、无障碍都齐，GPT 手写行容易对不齐。
  - 否掉的原因：项目用 Windows App SDK 2.5.1，Toolkit 8.x 按 1.x 构建，自包含发布有兼容风险；需要的行样式只有三四种，收进 `MainWindow.Layout.cs` 的辅助方法一样能防走样。改用零依赖样式（PAGES.md 第 5 节）。
- **重品牌皮肤，或者暗色极客仪表盘。**
  - 最强的理由：辨识度高，和别的工具一眼区分开。
  - 否掉的原因：winhand 管着密钥和桌面操作权限，属于 impeccable 说的 Operate 界面，可信要靠熟悉的原生秩序；非标控件、霓虹装饰只会显得像套壳。
- **百分之百系统默认的 WinUI。**
  - 最强的理由：零设计成本，永远和系统一致。
  - 否掉的原因：现状基本就是这样，炭灰强调色加纯白画布，主人的原话就是「太丑」。
- **会话页并进活动页。**
  - 最强的理由：少一个导航项，会话本来也是活动的一种。
  - 否掉的原因：会话要能停止、看日志，是可操作的对象，并进时间线会混。改成平时隐藏、有会话才出现，功能全保留。
- **悬浮提示条放右上角。** Gemini 第一轮的位置。
  - 否掉的原因：打开时会盖住页首的主操作（添加密钥、授权文件、编辑）。改到右下角。

## Acceptance criteria

- **截图验收**：主人电脑上用预览底座按 853×1018 逐页截图，`PAGES.md` 第 6 节的每一条都满足，Gemini 对照样稿认可。
- **功能和不变量**：
  - 密钥显示、复制、修改、删除，程序授权的开关、加入、撤销、恢复，中转保存，MCP 的增删改测，会话停止：在预览里走一遍，结果和改版前一样；
  - 密钥的不变量逐条复核。
- **CI**：desktop.yml 的构建通过。

## Risks

- **WinUI 细节和样稿不一致**：Mica、标题栏融合、InfoBadge 的颜色，HTML 样稿做不到一模一样。以截图验收为准，差异由 Gemini 判断能不能接受。
- **GPT 审美弱**：容易照搬旧样式或加装饰。说明里贴「不许做」清单，审查时逐条对。
- **深色模式**：主人平时用浅色，深色的问题不容易被发现。截图验收加一轮深色。
- **回滚**：界面改动都在 `desktop/windows/` 里，协议不变，有问题可以整体回退到 0.14.0 的界面。
