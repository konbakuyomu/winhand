# 一行安装

## 做成以后是什么样

在电脑的 PowerShell 里运行页面给的那一行，几分钟后托盘程序已装好、开机自启、连上中转，最后打印连接器地址。之后更新照旧在 App 里点。

## 方案

安装脚本由中转在 `/i/<码>` 返回，模板在 `relay/src/` 里，一次性码和中转地址由中转填进去。步骤：

1. 用 `POST /i/<码>` 换到电脑名称、令牌、连接地址。先做这一步，命令失效时不白下载 100 MB。
2. 下载 `https://github.com/konbakuyomu/winhand/releases/latest/download/SHA256SUMS.txt`，从里面找 `winhand-<版本>-Setup.exe` 这一行，再下载这个文件并核对 SHA256。这样不用调 GitHub API，0.11.0 也能用。
3. 已经装过同一版本时跳过安装；否则运行 `Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /MERGETASKS=autostart`。
   - Inno Setup 的 `autostart` 任务会写入和 App 一样的开机自启项。
   - 托盘程序正在运行时，安装程序会把它关掉。
4. 运行 `<安装目录>\current\backend\winhand.exe login --url <连接地址> --token-stdin`，令牌经 stdin 传入。
5. 经 `explorer.exe` 启动 `<安装目录>\winhand.exe`，和安装向导的「运行 winhand」一样。
6. 等 `/pc/<名称>/status.json` 变成在线，最多 60 秒，然后打印连接器地址；超时就打印怎么查。

- `winhand login`：只把地址和令牌写进 `~/.winhand/config.toml`，不连接；令牌可以从 stdin 读，不出现在命令行和进程列表里。
- 安装目录：读 Inno Setup 写的卸载项 `InstallLocation`；没有就用默认的 `%LocalAppData%\Programs\winhand`。
- 脚本兼容 Windows PowerShell 5.1：不用 `??` 这类 7 才有的语法；`Invoke-WebRequest` 加 `-UseBasicParsing`。

## 验证

- 在 GitHub Actions 的 windows-latest 上跑：
  - 本地起 `wrangler dev` 当中转；
  - 用接口配对、取脚本、运行；
  - 检查安装目录、开机自启项、`config.toml`，再用 `backend\winhand.exe connect` 连上中转，`status.json` 显示在线。
  - 托盘程序在 CI 上不一定起得来，所以连接用后端单独验证。
- `winhand login` 的单元测试：写入、覆盖原地址、令牌只从 stdin 读。
- 不在主人这台电脑上试装，免得覆盖正在用的 winhand。主人重新配对这台电脑时，就是真机验证。

## 执行记录

- 安装脚本模板在 `relay/src/install.ts`，由中转在 `GET /i/<码>` 返回；`winhand login` 在 `agent/src/winhand/cli.py`。
- 和方案的偏差：
  - 安装包外层是 Inno Setup 向导，静默参数用 `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /MERGETASKS=autostart`，不是 Velopack 的 `--silent`；
  - 安装目录从 Inno 的卸载项读；
  - 启动走 explorer.exe，和向导的「运行 winhand」一样。
- 给 CI 留的两个开关：
  - `WINHAND_INSTALLER`：用本地刚构建的安装包，不去下载；
  - `WINHAND_NO_START`：CI 机器上不启动托盘。
- CI：`.github/workflows/desktop.yml` 构建出安装包以后，跑 `relay/test/Install-E2E.ps1`：
  1. 本地起 wrangler dev；
  2. 在首页配对；
  3. 用 Windows PowerShell 5.1 运行页面给的那一行；
  4. 检查安装、开机自启、`config.toml`，以及同一条命令不能再用；
  5. 用装好的后端连上中转，`/pc/ci/status.json` 变成在线。
- `winhand login` 的单元测试在 `agent/tests/test_multi_pc.py`。
- codestable：现状规格等 Epic 关闭时合并；这次改动的取舍见 `.agents/notes/implemented/architecture/2026-11-18-multi-pc-relay.md`。

- 第一次跑 CI 的 Windows 端到端测试（desktop.yml run 44134904282），找出一个真问题：
  - Windows PowerShell 把令牌通过管道交给 `winhand login` 时，在前面加了 UTF-8 BOM，存下的令牌成了 `ï»¿…`，电脑会连不上中转。11-13 迁移 LAX 时也踩过同类的坑。
  - 两边都改：脚本把 `$OutputEncoding` 设成不带 BOM 的 UTF-8；`winhand login` 按字节读 stdin，去掉 BOM。新增单元测试。
  - 测试里检查 `config.toml` 的正则原来只认双引号，改成单双引号都认（`config.save` 写的是单引号）。
- 版本号改成 0.12.0，三处：`agent/pyproject.toml`、`agent/src/winhand/__init__.py`、`agent/uv.lock`。
- 改完重跑（desktop.yml run 44137068875，提交 4f4315d），通过：
  - 用签了名的正式安装包，在 Windows PowerShell 5.1 里运行首页给的那一行；
  - 配对、静默安装、开机自启、`config.toml` 里是干净的 43 个字符的令牌、同一条命令不能再用、装好的后端以 `/pc/ci` 连上中转；
  - 整步 35 秒。
- 还差真机：主人在另一台电脑上跑一次（不在主力电脑上试装，原因见上）。
