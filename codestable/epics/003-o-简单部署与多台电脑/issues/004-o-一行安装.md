# 一行安装

## 做成以后是什么样

在电脑的 PowerShell 里运行页面给的那一行，几分钟后托盘程序已装好、开机自启、连上中转，最后打印连接器地址。之后更新照旧在 App 里点。

## 方案

安装脚本由中转在 `/i/<码>` 返回，模板在 `relay/src/` 里，一次性码和中转地址由中转填进去。步骤：

1. 用 `POST /i/<码>` 换到电脑名称、令牌、连接地址。先做这一步，命令失效时不白下载 100 MB。
2. 下载 `https://github.com/konbakuyomu/winhand/releases/latest/download/SHA256SUMS.txt`，从里面找 `winhand-<版本>-Setup.exe` 这一行，再下载这个文件并核对 SHA256。这样不用调 GitHub API，0.11.0 也能用。
3. 已经装过同一版本时跳过安装；否则运行 `Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /MERGETASKS=autostart`。
   - Inno Setup 的 `autostart` 任务会写入和 App 一样的开机自启项。
   - 托盘程序正在运行时，安装程序会把它关掉。
4. 运行 `<安装目录>\current\backend\winhand.exe login --url <连接地址> --token-stdin`，令牌经 stdin 传入。
5. 经 `explorer.exe` 启动 `<安装目录>\winhand.exe`，和安装向导的「运行 winhand」一样。
6. 等 `/pc/<名称>/status.json` 变成在线，最多 60 秒，然后打印连接器地址；超时就打印怎么查。

- `winhand login`：只把地址和令牌写进 `~/.winhand/config.toml`，不连接；令牌可以从 stdin 读，不出现在命令行和进程列表里。
- 安装目录：读 Inno Setup 写的卸载项 `InstallLocation`；没有就用默认的 `%LocalAppData%\Programs\winhand`。
- 脚本兼容 Windows PowerShell 5.1：不用 `??` 这类 7 才有的语法；`Invoke-WebRequest` 加 `-UseBasicParsing`。

## 验证

- 在 GitHub Actions 的 windows-latest 上跑：
  - 本地起 `wrangler dev` 当中转；
  - 用接口配对、取脚本、运行；
  - 检查安装目录、开机自启项、`config.toml`，再用 `backend\winhand.exe connect` 连上中转，`status.json` 显示在线。
  - 托盘程序在 CI 上不一定起得来，所以连接用后端单独验证。
- `winhand login` 的单元测试：写入、覆盖原地址、令牌只从 stdin 读。
- 不在主人这台电脑上试装，免得覆盖正在用的 winhand。主人重新配对这台电脑时，就是真机验证。
