# 概览、活动、MCP 服务与会话四页

## 做成以后是什么样

按 `../PAGES.md` 4.1–4.4 节做这四页，样稿是主人电脑上 `mockups/overview.html`、`mockups/activity.html`、`mockups/mcp.html`。

- **概览**：
  - 一张状态卡：连接状态、主机、在线时长、断开和重新连接，下面三格指标（今日调用、MCP 服务、活动会话）；
  - 需要时显示一条状态提示（未配置、令牌被拒、有新版本）；
  - 最近活动 8 条，行可以点，悬停时出现右箭头，点了跳到活动页并选中这条。
- **活动**：
  - 工具栏两行：标题、搜索、审计日志一行，筛选和计数一行，「失败」不会被挤掉；
  - 内容区宽于 760 时左右分栏；窄时选中一条，底部弹出详情抽屉，Esc 关闭；
  - Ctrl+F 聚焦搜索；
  - 工具名用等宽字体，中文标题用界面字体。
- **MCP 服务**：
  - 分栏阈值 568，853 宽时直接左右分栏；
  - 详情头右边是「编辑」和「⋯」菜单，删除在菜单里；
  - 远程访问、运行、启动方式三张卡。
- **会话**：功能不变，样式对齐新规范。
